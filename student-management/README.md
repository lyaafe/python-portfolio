# Student Management System

A simple student management application developed using Python.

## Features

- Add new students
- Display all students
- Delete students
- Save student information in a CSV file
- Load student information from a CSV file

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- CSV Module

## Project Structure

```text
student-management/
│
├── main.py
├── st.csv
└── README.md
```

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## About

This project was created to practice Python programming, Object-Oriented Programming (OOP), file handling, and basic data management using CSV files.
