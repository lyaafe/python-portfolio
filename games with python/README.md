# Python Mini Arcade

A collection of simple Python games and a calculator application, developed to practice fundamental Python programming concepts.

## Features

### Games
- Hoop Game
- Dice Guessing Game

### Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Exponentiation

### Other Features
- Interactive menu system

## Technologies Used

- Python 3
- Functions
- Object-Oriented Programming (OOP)
- Loops and Conditional Statements
- Random Module

## Project Structure

```text
games-with-python/
│
├── main.py
├── requirements.txt
└── README.md
```

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Install the required dependencies:

```bash
pip install -r requirements.txt
```

5. Run the application:

```bash
python main.py
```

## About

This project was created as a Python practice project to improve programming skills through simple games, calculations, and interactive menus.
