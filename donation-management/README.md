# Donation Management System

A simple donation management and analysis application developed with Python.

## Features

- Add donation records
- Display donation information
- Calculate total donations
- Calculate average donations
- Identify the highest donor
- Analyze donation data

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Loops
- Conditional Statements

## Project Structure

```text
donation-management/
│
├── main.py
└── README.md
```

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## About

This project was developed to practice Python functions, dictionaries, loops, and basic data analysis.
