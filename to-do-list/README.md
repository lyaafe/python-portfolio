# To-Do List Application

A simple task management application developed with Python using Object-Oriented Programming.

## Features

- Add new tasks
- Display all tasks
- Remove tasks
- Save tasks in a CSV file
- Load saved tasks from a CSV file

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- CSV Module
- File Handling
- Exception Handling

## Project Structure

```text
to-do-list/
│
├── main.py
├── tasks.csv
└── README.md
```

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## About

This project was developed to practice Python classes, lists, file handling, CSV operations, and error management.
